Read-only profile manual

You have read-only access to one or more retreats. You can look up the attendants and how many letters each one has received, read the contact log and, above all, get each attendant's link so their family and friends can write to them. You can't change anything or open the letters, so there's no way you can break anything.

1. How it works

  1. Each attendant has a private URL for receiving letters. You pass it on to their family and friends, usually through their emergency contact.
  2. The writer opens the link in any browser, without signing up. They write their letter or attach photos and documents, and send it.
  3. The letter is stored encrypted. Nobody can read it on screen; you see how many letters each attendant has, but not who wrote them or what they say.
  4. During the retreat, the team prints the letters and hands them out to each attendant.

Everything lives under the Retreats menu in the WordPress dashboard. All Retreats shows the retreats where you have any permission; click Attendants or the retreat name to go in.

2. What you can do

Permissions are granted per retreat: in another retreat you may have a different profile or none at all. In the retreats where you have read-only access:

  • You can:
    • see the attendants list, active and withdrawn, and how many letters each one has;
    • view each attendant's record;
    • copy each attendant's message URL and invitation message;
    • read the contact log.
  • You can't: change any details, withdraw anyone, write in the log, import or export attendants, or open, print or download letters. You also don't see the retreat settings or who has access. If you need any of this, talk to the retreat manager.

3. The attendants list

At the top you'll see the total number of attendants and a letter summary. There are two tabs: Attendants (those going on the retreat) and Withdrawn attendants (those who end up not going; they no longer receive letters).

Columns

  • The attendant's details: First Name, Last Name, Emergency Contact and the others the retreat has enabled.
  • Messages: letters received through the website.
  • Physical Letters: paper letters received outside the website.
  • Total Letters: the sum of the two previous columns. Sort by this column to see who has few letters.
  • Contact Log: a notebook icon with the number of entries. Click it to open the log.

On a computer, the list scrolls inside its own pane, like a spreadsheet: the headers, the name and the action buttons always stay in sight. On narrow screens, such as a phone, each attendant is shown as a card with the full name on top and without the empty values, and a Sort by drop-down appears.

Searching, filtering and sorting

The search box looks in first name, last name, emergency contact, invited by and incompatibilities. Under Filters you can filter by each of those fields; click Apply Filters or Clear Filters. Click a column header to sort by it.

Filters also lists the retreat's custom fields that you can see. Text fields are filtered by what they contain; Options list and Yes/No fields, with a drop-down; numbers and dates, with a From–To range in which you can fill in just one end.

Buttons for each attendant

  • View: opens their record, with all fields locked. Back to Attendants takes you back to the list.
  • Invitation Message: see below. It only appears if the retreat has a template.
  • Generate Message URL or Copy Message URL: see The link for the letters.

4. The link for the letters

Each attendant has a unique address, something like https://yourparish.org/messages/secret-code, which is the way in to write to them. The code is random and can't be guessed.

  • Copy Message URL copies it to the clipboard with the attendant's initials at the end (for example, …/messages/code/#JGP), so you know whose link it is without showing their name. Paste it wherever you like: an email, a WhatsApp message…
  • If the attendant doesn't have a link yet, you'll see Generate Message URL. Click it and the link is created. If they already have one, it is never changed: links already handed out keep working.
  • Share the link only with people who should write. Anyone who has it can send letters to that attendant.
  • The link stops working if the attendant is withdrawn.

The invitation message

If the team has prepared a template, the Invitation Message button shows the text already filled in with the attendant's details and link: the message sent to the family or emergency contact asking them to write and to encourage others to do the same. Copy it and paste it into an email or WhatsApp. If the attendant doesn't have a link yet, click Generate Message URL first; otherwise the message will come out without it.

5. Contact log

This is where the team writes down calls and conversations with each attendant's contact person: "Called his mother on Tuesday, she'll send the link to his brothers", and so on. Open it from the Contact Log column in the list or from the record. Before calling a family, check it to see whether someone has already spoken to them.

You can read it, but not write in it. If you've spoken to someone and it needs to be noted down, tell a retreat manager or a message manager.

6. The letter form

This is the page people see when they open an attendant's link. No account on the website is needed. It's worth knowing it well so you can help the families.

  • At the top are the attendant's name and the message the team has prepared for letter writers.
  • There may be a Language selector. Changing the language doesn't reload the page, so nothing already written is lost.
  • The writer enters their name and, optionally, their email (twice, to avoid typos). The email is only used to let them know about any problem with their letter, such as it being returned if the attendant doesn't end up going on the retreat.
  • They choose the message type:
    • Text Message: an editor with bold, italic, underline, lists and undo/redo. Images and text copied from Word or Google Docs can be pasted in.
    • File Upload: photos or documents (PDF, DOC, DOCX, TXT, JPG, PNG, GIF). The form shows the maximum size the server accepts.
  • They solve the Security Check, a simple sum.
  • If the retreat has a legal disclaimer, the acceptance box must be ticked; the send button stays disabled until then.
  • After clicking Send Confidential Message, a page confirms that the letter has been received. Shortly afterwards, the attendant's letter count goes up in the list.

7. FAQ and troubleshooting

Can I read the letters?

No. Nobody can read them on screen: they can only be seen when printed, and only retreat managers and message managers can print them. You see how many letters each attendant has.

A relative says the link doesn't work.

Check that they copied the whole address and that the attendant hasn't been withdrawn. If they see "Too many requests", they should wait an hour and try again. If it still doesn't work, let a retreat manager know.

Uploading files gives a size error.

The limit is set by the server and shown on the form. Send smaller files, or fewer at a time.

I can't see the Invitation Message button.

It only appears if the retreat manager has written a template. In the meantime, you can copy the link with Copy Message URL and write the message yourself.

An attendant's details are wrong.

You can't change them. Tell the retreat manager.

I can't see a retreat in the list.

You only see the retreats where you have permission. Ask the retreat manager for access.

Found a mistake or missing something? Let us know on GitHub or in the WordPress.org support forum.
