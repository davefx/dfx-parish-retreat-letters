Message manager manual

You are a message manager for one or more retreats: you look after the letters. You print them to hand out during the retreat, delete them if needed and return them by email to whoever wrote them when an attendant doesn't end up going. You also see the attendants, record paper letters and keep the contact log with the families. Letters arrive encrypted and nobody can read them on screen: they can only be seen when printed.

1. How it works

  1. Each attendant has a private URL for receiving letters. The team passes it on to their family and friends, usually through their emergency contact.
  2. The writer opens the link in any browser, without signing up. They write their letter or attach photos and documents, and send it.
  3. The letter is stored encrypted. The admin area only shows who sent it, when, and what kind of letter it is; never its content.
  4. You print the letters during the retreat. Every print is logged with the user, the date and the IP address.
  5. The letters are handed out to each attendant whenever the team decides.

Everything lives under the Retreats menu in the WordPress dashboard. All Retreats shows the retreats where you have any permission; click Attendants or the retreat name to go in.

2. What you can do

Permissions are granted per retreat: in another retreat you may have a different profile or none at all. In the retreats where you are a message manager:

  • You can:
    • see the attendants list, active and withdrawn, with their letter counts;
    • open, print, delete and return letters by email;
    • record paper letters received;
    • change the custom fields that the retreat manager has opened to message managers;
    • write in the contact log;
    • copy each attendant's message URL and invitation message.
  • You can't: change the retreat settings, grant permissions, add, edit, withdraw or reactivate attendants, import or export CSV, or empty the retreat. For any of that, talk to the retreat manager.

3. Attendants

The attendants list

At the top you'll see the total number of attendants and a letter summary: how many messages have been received, how many are still to be printed and the total including physical letters. There are two tabs: Attendants (the active ones) and Withdrawn attendants.

Columns

  • The attendant's details: First Name, Last Name, Emergency Contact and the others the retreat has enabled, including the custom fields visible to you.
  • Messages: letters received through the website and, in brackets, those still to be printed. Clicking the header repeatedly sorts by total or by letters pending printing.
  • Physical Letters: paper letters received outside the website.
  • Total Letters: the sum of the two previous columns.
  • Contact Log: a notebook icon with the number of entries. Click it to open the log in a pop-up window.

On a computer, the list scrolls inside its own pane, like a spreadsheet: the headers, the name and the action buttons always stay in sight. Each click on the Name and Surnames header sorts the list by name, then by surnames, and then the same in reverse order; when not all the columns fit, the surnames go under the name. On narrow screens, such as a phone, each attendant is shown as a card with the full name on top and without the empty values, and a Sort by drop-down appears.

Searching, filtering and sorting

The search box looks in first name, last name, emergency contact, invited by and incompatibilities. Under Filters you can filter by each of those fields and by notes; click Apply Filters or Clear Filters. Click a column header to sort by it.

Filters also lists the retreat's custom fields that you can see. Text fields are filtered by what they contain; Options list and Yes/No fields, with a drop-down; numbers and dates, with a From–To range in which you can fill in just one end.

Inline editing

You can change Physical Letters and the custom fields you're allowed to edit without opening the record: click the cell, type, and press Enter to save or Esc to cancel.

Buttons for each attendant

  • Edit: opens the record in restricted mode (see below).
  • Messages: opens their letters.
  • Invitation Message: shows the request template filled in with their details and link, ready to copy and paste into an email or WhatsApp. It only appears if the retreat has a template.
  • Generate Message URL or Copy Message URL: see below.

The attendant record

It opens in restricted mode: you see all their details, but you can only change Physical Letters Received, the custom fields you're allowed to edit and the Contact Log. The record also shows the number of messages received, with a link to them, and their Message URL.

The message URL

Each attendant has a unique address, something like https://yourparish.org/messages/secret-code, which is the way in to write to them. The code is random and can't be guessed.

  • If the attendant doesn't have one yet, click Generate Message URL.
  • Copy Message URL copies it to the clipboard with the attendant's initials at the end (for example, …/messages/code/#JGP), so you know whose link it is without showing their name.
  • Share the link only with people who should write. Anyone who has it can send letters to that attendant.

Contact log

This is where the team writes down calls and conversations with each attendant's contact person: "Called his mother on Tuesday, she'll send the link to his brothers", and so on. Open it from the Contact Log column in the list or from the record.

  • Add entries with a date and a description using Add Entry.
  • You can correct your entries for 15 minutes and delete them at any time. Edited entries are marked "(edited)".
  • Only the retreat manager can change other people's entries.

4. The letter form

This is the page people see when they open an attendant's message URL. No account on the website is needed. It's worth knowing it well so you can help the families.

  • At the top are the attendant's name and the message the team has prepared for letter writers.
  • There may be a Language selector. Changing the language doesn't reload the page, so nothing already written is lost.
  • The writer enters their name and, optionally, their email (twice, to avoid typos). The email is stored encrypted and is only used to let them know about any problem with their letter, such as it being returned if the attendant doesn't end up going on the retreat.
  • They choose the message type:
    • Text Message: an editor with bold, italic, underline, lists and undo/redo. Images and text copied from Word or Google Docs can be pasted in.
    • File Upload: photos or documents (PDF, DOC, DOCX, TXT, JPG, PNG, GIF). The form shows the maximum size the server accepts.
  • They solve the Security Check, a simple sum.
  • If the retreat has a legal disclaimer, the acceptance box must be ticked; the send button stays disabled until then.
  • After clicking Send Confidential Message, a page confirms that the letter has been received.

If the attendant has withdrawn, the form shows "Messages are no longer being accepted for this attendant."

5. Confidential messages: printing, deleting and returning

The messages list

Open it with each attendant's Messages button. For security, it never shows the content of the letters, only their details: sender, type (text or files), date sent and print status. You can filter by type, search by sender and sort by any of those columns, including print status (unprinted first).

Printing

  1. Click Print on the letter.
  2. A new tab opens with the letter ready to print: recipient, sender and content. It is decrypted at that moment.
  3. The browser's print dialog opens. When you close it, the tab closes by itself.
  • Letters with several images are laid out so that no image is split across two pages.
  • If the letter is a single PDF, a "From/To" header is usually added at the top so you know who it's from and who it's for.
  • If there are several files and any of them isn't an image, they are all downloaded together in a ZIP file. Word documents can't be shown in the print view: download them and print them separately.
  • Use an up-to-date browser (Edge, Chrome, Firefox or Safari). Internet Explorer is not supported and won't show the letters.

Print history

Each letter's status tells you whether it has been printed, how many times and when it was first printed. Click it to see the full history: who printed it, when and from which IP. Print each letter only once if possible and keep the paper copies safe.

Deleting a letter

Delete removes the letter, its files and its print history. It can't be undone.

Returning letters by email

When an attendant withdraws (for example, because they end up not going on the retreat), their letters can be returned to the people who wrote them, as long as they left their email:

  • Return by email returns one letter; Return all by email returns every letter that can be returned.
  • Before sending, a preview shows the recipient, subject, text and attachments. Text letters are attached as an HTML document; file letters, with the original files.
  • Once the email is sent, the letter is deleted from the system. If sending fails, the letter is kept.
  • If the letter had already been printed, you're reminded to destroy the paper copy.
  • Letters without an email are shown as "No email: cannot be returned".

The email subject and text are prepared by the retreat manager.

6. Withdrawn attendants

When the retreat manager withdraws someone, the attendant moves to the Withdrawn attendants tab, with the date and the user who withdrew them. Their URL stops accepting letters, but nothing is deleted: their letters are still there, and you can print them or return them by email. Their contact log stays open.

If the attendant does end up going on the retreat, ask the retreat manager to reactivate them.

7. The letters, from start to finish

  1. Asking for letters. For each attendant, copy the Invitation Message and send it to their emergency contact. Note in the contact log who you've called or written to.
  2. Follow-up. Check the list for anyone with few letters (sort by Total Letters) and get back in touch if needed. Record paper letters under Physical Letters.
  3. Withdrawals. If someone isn't going, return their letters by email as soon as the manager withdraws them.
  4. During the retreat. Print the letters (sort by Messages to see those still to be printed) and get them ready to hand out. Before handing them out, check in the list that none are left unprinted.
  5. Afterwards. Destroy any spare copies. The retreat manager will empty the retreat to delete the personal data.

8. FAQ and troubleshooting

Who can read the letters?

Nobody, on screen. They can only be seen when printed, and only that retreat's retreat managers and message managers and the plugin administrators can print them. Every print is logged.

A relative says the link doesn't work.

Check that they copied the whole address and that the attendant hasn't been withdrawn. If they see "Too many requests", they should wait an hour, or you can ask a plugin administrator to reset the limits.

Uploading files gives a size error.

The limit is set by the server and shown on the form. Send smaller files, or fewer at a time.

A letter doesn't print properly.

Try another up-to-date browser. If they are Word documents, download them and print them separately. If the letter has several files and any of them isn't an image, they are downloaded in a ZIP file.

I can't see the Invitation Message button.

It only appears if the retreat manager has written a request template.

I can't change an attendant's details.

Your profile only lets you change physical letters, some custom fields and the contact log. For anything else, talk to the retreat manager.

I can't see a retreat in the list.

You only see the retreats where you have permission. Ask the retreat manager for access.
